## What is AWS?

**Amazon Web Services (AWS)** is a cloud computing platform that provides a large collection of on-demand IT services.

These services include:

* Compute
* Storage
* Databases
* Networking
* Security
* Monitoring
* Analytics
* Machine Learning
* Application Integration
* Developer Tools

Instead of purchasing and maintaining all the required physical infrastructure, organizations can consume these capabilities as cloud services.
