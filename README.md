# AWS Studies ☁️

My AWS learning journey.

This repository contains my notes, summaries, practical exercises, and personal insights while studying **Amazon Web Services (AWS)**.

The goal is to document what I learn, organize my knowledge, and build a reference that I can use for future studies and certification preparation.

> **Disclaimer:** This is a personal study repository. The content represents my understanding and notes from my studies and is not official AWS documentation.

## 🧠 How I Organize My Notes

Each topic is organized using Markdown files.

Whenever possible, my notes include:

* **Concept** — What is it?
* **How it works** — How does it work?
* **Why it matters** — Why is it important?
* **Examples** — Practical examples.
* **Analogies** — Simple ways to understand the concept.
* **Key Takeaways** — What I need to remember.
* **My Notes** — Personal observations and insights.
* **Hands-on** — Practical exercises when applicable.
