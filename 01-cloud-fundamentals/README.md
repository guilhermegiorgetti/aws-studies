## Key Concepts

### Cloud Computing

Cloud computing is the on-demand delivery of IT resources over the internet, typically with pay-as-you-go pricing.

Examples of cloud resources include:

* Compute
* Storage
* Databases
* Networking
* Applications
* Security services
* Monitoring
* Machine learning services

---

## The Three Main Cloud Service Models

| Model    | Main Idea                                     |
| -------- | --------------------------------------------- |
| **IaaS** | Rent infrastructure                           |
| **PaaS** | Use a managed platform to deploy applications |
| **SaaS** | Use a complete software application           |

---

## Key Takeaways

> Cloud computing allows organizations to consume IT resources on demand instead of owning and maintaining all the underlying infrastructure themselves.

The main ideas to remember are:

* Pay for what you use.
* Scale resources according to demand.
* Avoid large upfront infrastructure investments.
* Increase speed and agility.
* Build highly available and fault-tolerant systems.
* Deploy applications globally.
