# What is Cloud Computing? ☁️

## Introduction

Cloud computing is the delivery of computing resources over the internet on demand.

Instead of purchasing and maintaining physical servers, organizations can use resources provided by cloud providers such as AWS.

The basic idea is:

> **Use IT resources when you need them and pay according to your usage.**

---

# Before Cloud Computing

In a traditional environment, an organization might need to purchase and maintain:

* Physical servers
* Storage
* Networking equipment
* Power infrastructure
* Cooling systems
* Data centers
* Operating systems
* Databases
* Security infrastructure

The organization is responsible for maintaining the infrastructure.

This requires significant **capital expenditure (CapEx)** and operational effort.

---

# A Basic Client-Server Model

A simplified representation of communication between a client and a server is:

```text
Client
   │
   ▼
Network
   │
   ▼
Server
   │
   ▼
Network
   │
   ▼
Client
```

The client sends a request through the network.

The server processes the request and sends a response back through the network.

---

# IP Address

An **IP address** is a numerical address used to identify a network interface and enable communication between devices and services over an IP network.

For example:

```text
Client
IP: 192.168.1.10

        │
        ▼

Server
IP: 192.168.1.20
```

A useful analogy is an address on a letter.

The address helps the network determine where the information needs to go.

> **Important:** An IP address identifies a network endpoint. It is not exactly the same as a person's physical address, but the analogy helps understand the basic idea.

---

# What is Cloud Computing?

Cloud computing is the **on-demand delivery of IT resources over the internet**, usually with pay-as-you-go pricing.

These resources can include:

* Compute
* Storage
* Databases
* Networking
* Applications
* Security
* Monitoring
* Machine learning
* Analytics

Instead of buying all the hardware yourself, you can consume infrastructure and services from a cloud provider.

---

# Pay-As-You-Go

One of the fundamental ideas of cloud computing is:

> **Pay only for the resources you use.**

For example, instead of buying a physical server that may remain underutilized, you can create a virtual server in the cloud and pay for its usage.

This allows organizations to adapt their infrastructure according to their needs.

---

# Physical Server vs. Cloud Server

### Traditional environment

```text
Company
   │
   ├── Buys server
   ├── Installs server
   ├── Provides power
   ├── Provides cooling
   ├── Maintains hardware
   └── Manages infrastructure
```

### Cloud environment

```text
Company
   │
   ▼
Cloud Provider
   │
   ├── Compute
   ├── Storage
   ├── Networking
   └── Infrastructure
```

The cloud provider manages the underlying physical infrastructure while the customer consumes the resources and services.

# Cloud Services We Already Use

Cloud computing is not a completely new concept for most people.

Many everyday services use cloud infrastructure.

Examples include:

* Gmail
* Online file storage
* Streaming platforms
* Online collaboration tools
* Web applications
* Online banking

For example, Gmail provides email as an online service without requiring the user to maintain an email server.

---

# Video on Demand

A video streaming service is an example of **Video on Demand (VOD)**.

Instead of downloading or physically owning a movie, the user requests the content when they want to watch it.

```text
User
 │
 ▼
Internet
 │
 ▼
Cloud Infrastructure
 │
 ▼
Video Content
```

---

# Why Cloud Computing?

Cloud computing allows organizations to:

* Start using infrastructure quickly.
* Scale resources up or down.
* Avoid large hardware purchases.
* Access resources globally.
* Pay according to usage.
* Focus more on applications and business requirements.

---

# Key Takeaways

* Cloud computing delivers IT resources on demand.
* Resources are typically accessed over a network or the internet.
* Customers can pay according to usage.
* Cloud computing reduces the need to own physical infrastructure.
* Cloud resources can be scaled according to demand.
* Compute, storage, databases, and networking are fundamental cloud resources.
